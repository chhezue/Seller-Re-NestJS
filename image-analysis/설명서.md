# 모델 학습 방법 안내

새로운 이미지를 추가한 후 모델을 다시 학습시키는 방법입니다.

## 1. 데이터 추가

- 학습 이미지 추가: `image-analysis/dataset/train/<카테고리명>/` 폴더에 새로운 이미지를 추가합니다.
- 검증 이미지 추가: `image-analysis/dataset/validation/<카테고리명>/` 폴더에 새로운 이미지를 추가합니다.

예시) 새로운 '도서' 카테고리 사진은 `dataset/train/도서` 및 `dataset/validation/도서` 폴더에 넣습니다. 카테고리 폴더가 없다면 새로 만듭니다.

## 2. 학습 실행

아래 명령어를 `image-analysis` 폴더에서 실행하면, 기존 임시 데이터셋을 삭제하고 최신 데이터셋을 복사한 후 학습을 시작합니다.

```bash
# image-analysis 폴더 안에서 실행해야 합니다.
rm -rf temp_dataset && cp -r dataset temp_dataset && venv/bin/python fine_tune.py
```

## 3. (참고) 라이브러리 설치

만약 `fine_tune.py` 실행 중 `ModuleNotFoundError` 와 같은 에러가 발생하면, 필요한 라이브러리가 설치되지 않은 것입니다. 아래 명령어로 라이브러리를 설치해주세요.

```bash
# image-analysis 폴더 안에서 실행해야 합니다.
venv/bin/pip install -r requirements.txt
```
