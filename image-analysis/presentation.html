📸 Image Analysis 서비스

이 문서는 이미지 분석 서비스의 설치, 모델 학습, 그리고 실행 방법을 안내합니다.
서비스는 상품 이미지를 입력받아 적절한 카테고리를 예측하는 딥러닝 모델을 기반으로 합니다.

1. 초기 설정: 환경 준비

서비스를 실행하기 전에 Python 가상 환경을 설정하고 필요한 라이브러리를 설치해야 합니다.

image-analysis 디렉토리에서 아래 명령어를 실행하세요.

# 가상환경(venv)의 pip를 사용하여 requirements.txt에 명시된 라이브러리를 설치합니다.
venv/bin/pip install -r requirements.txt
참고: ModuleNotFoundError와 같은 오류가 발생하면 대부분 의존성 라이브러리가 제대로 설치되지 않았기 때문입니다. 위 명령어를 다시 실행해 주세요.

2. 모델 및 학습 방식

본 서비스는 최신 이미지 분류 기술을 활용하여 높은 정확도를 목표로 합니다.

2.1. 기반 모델

Google이 개발한 Vision Transformer(ViT) 모델을 기반으로 합니다. 구체적으로는 google/vit-base-patch16-224 사전 학습 모델을 사용합니다. 이 모델은 대규모 이미지 데이터셋으로 미리 학습되어 있어, 이미지의 복잡한 패턴과 특징을 이해하는 능력이 뛰어납니다.

2.2. 파인 튜닝 (Fine-tuning)

사전 학습된 ViT 모델을 우리 서비스의 특정 카테고리(예: 디지털기기, 생활가전 등)에 맞게 성능을 최적화하는 '파인 튜닝' 과정을 거칩니다. 이 과정은 fine_tune.py 스크립트를 통해 이루어집니다.

  • 데이터 증강(Augmentation): 한정된 데이터셋으로도 모델이 다양한 상황에 대응할 수 있도록 원본 이미지를 무작위로 변형(회전, 자르기, 좌우 반전 등)하여 학습 데이터의 양과 다양성을 늘립니다.
  • 추가 학습: 증강된 커스텀 이미지 데이터(dataset/train)를 사용하여 모델을 추가로 학습시킵니다. 이 과정을 통해 모델은 우리 서비스에 특화된 이미지 분류 능력을 갖추게 됩니다.

3. 모델 학습 실행

3.1. 데이터셋 준비

학습 및 검증용 이미지를 지정된 폴더에 추가합니다. 카테고리별로 폴더가 나뉘어 있습니다.

  • 학습 이미지 경로: image-analysis/dataset/train/[카테고리명]/
  • 검증 이미지 경로: image-analysis/dataset/validation/[카테고리명]/

3.2. 학습 실행

데이터 준비가 완료되면, 아래 명령어를 image-analysis 디렉토리에서 실행하여 모델 학습을 시작합니다.

# 1. 기존 임시 데이터셋 삭제
# 2. 최신 데이터셋을 임시 폴더로 복사
# 3. fine_tune.py 스크립트를 실행하여 모델 학습 시작
rm -rf temp_dataset && cp -r dataset temp_dataset && venv/bin/python fine_tune.py

학습된 모델은 my_custom_model_v2 디렉토리에 저장됩니다.

3.3. 파인튜닝 코드 상세 분석 (fine_tune.py)

fine_tune.py 스크립트는 다음과 같은 단계로 모델 학습을 진행합니다.

1단계: 설정 및 초기화

학습에 필요한 주요 변수들을 설정합니다. 모델 저장 경로, 기반 모델 이름, 학습 파라미터(에포크, 배치 사이즈, 학습률) 등을 정의합니다.

# --- 1. 설정 (Configuration) ---
MODEL_OUTPUT_PATH = "my_custom_model_v2"
PRETRAINED_MODEL = "google/vit-base-patch16-224"

NUM_TRAIN_EPOCHS = 15
PER_DEVICE_TRAIN_BATCH_SIZE = 32
LEARNING_RATE = 3e-5

2단계: 데이터셋 로드 및 전처리

dataset/train, dataset/validation 폴더 구조를 기반으로 데이터셋을 만듭니다. 이미지 데이터는 모델 학습에 적합하도록 데이터 증강(회전, 자르기 등) 및 정규화 과정을 거칩니다.

# 폴더 경로에서 이미지와 라벨을 읽어 데이터셋 객체 생성
train_dataset, label2id = create_dataset_from_path("dataset/train")
eval_dataset, _ = create_dataset_from_path("dataset/validation")

# 데이터 증강 및 변환 정의
train_transforms = T.Compose([
    T.RandomResizedCrop(processor.size["height"]),
    T.RandomHorizontalFlip(),
    T.ToTensor(),
    normalize,
])

# 데이터셋에 변환 적용
train_dataset = train_dataset.map(train_transform, batched=True)
eval_dataset = eval_dataset.map(val_transform, batched=True)

3단계: 모델 로드

Hugging Face Hub에서 사전 학습된 ViT 모델을 로드합니다. 우리 데이터셋의 카테고리 수에 맞게 모델의 마지막 분류 레이어를 새로 초기화합니다.

model = ViTForImageClassification.from_pretrained(
    PRETRAINED_MODEL,
    num_labels=len(labels), # 우리 서비스의 카테고리 수
    label2id=label2id,
    id2label=id2label,
    ignore_mismatched_sizes=True, # 사전 학습된 모델과 크기가 다른 레이어는 무시
)

4단계: 학습 실행

transformers 라이브러리의 Trainer를 사용하여 실제 학습을 진행합니다. 학습 과정, 평가, 로그 기록 등을 자동으로 관리해줍니다.

training_args = TrainingArguments(...)

trainer = Trainer(
    model=model,
    args=training_args,
    train_dataset=train_dataset,
    eval_dataset=eval_dataset,
    compute_metrics=compute_metrics,
    tokenizer=processor,
)

# 학습 시작
trainer.train()

5단계: 모델 저장

학습이 완료된 모델과 이미지 전처리기(processor)를 지정된 경로(my_custom_model_v2)에 저장하여, 나중에 분석 API에서 불러와 사용할 수 있도록 합니다.

trainer.save_model(MODEL_OUTPUT_PATH)
processor.save_pretrained(MODEL_OUTPUT_PATH)

4. 이미지 분석 방식 및 서비스 실행

4.1. 분석 프로세스

API 서버를 통해 이미지 분석을 요청했을 때 내부적으로 다음과 같은 프로세스를 거칩니다.

  1. 모델 로드: 서버가 시작될 때, 파인 튜닝된 모델(my_custom_model_v2)과 이미지 전처리기(Processor)를 미리 메모리에 로드하여 빠른 응답을 준비합니다.
  2. 이미지 전처리: 사용자가 요청한 각 이미지 파일을 열고, 모델이 이해할 수 있는 표준 크기(224x224)와 형식의 숫자 데이터(텐서)로 변환합니다.
  3. 카테고리 확률 예측: 전처리된 각 이미지 데이터를 모델에 입력하여, 모든 카테고리에 대한 개별 확률(Logits)을 계산합니다.
  4. 확률 집계 및 평균 계산: 여러 장의 이미지에 대한 예측 결과를 종합합니다. 모든 이미지의 카테고리별 확률을 합산한 후, 이미지 개수로 나누어 평균 확률을 구합니다.
  5. 최종 결과 반환: 계산된 평균 확률이 가장 높은 상위 2개의 카테고리를 최종 예측 결과로 결정하여 사용자에게 반환합니다.

4.2. 이미지 분석 API 코드 상세 분석 (main.py & predictor.py)

이미지 분석 요청은 FastAPI로 구현된 main.py의 /analyze 엔드포인트에서 처리되며, 실제 예측 로직은 predictor.py의 predict_multiple 함수에 구현되어 있습니다.

1단계: API 요청 접수 (main.py)

클라이언트는 분석할 이미지 경로 리스트를 JSON 형식으로 /analyze 엔드포인트에 POST 요청으로 보냅니다. 서버는 이 요청을 받아 predict_multiple 함수를 호출합니다.

# main.py
@app.post("/analyze", response_model=AnalysisResponse)
def analyze_image(request: AnalysisRequest):
    try:
        # 여러 이미지에 대한 예측 함수 호출
        prediction_results = predict_multiple(request.image_paths)
        
        # 결과를 응답 모델에 맞게 변환
        response_results = [AnalysisResult(**item) for item in prediction_results]
        
        return AnalysisResponse(results=response_results)
    except Exception as e:
        raise HTTPException(status_code=500, detail=str(e))

2단계: 다중 이미지 예측 및 확률 집계 (predictor.py)

predict_multiple 함수는 전달받은 이미지 경로 리스트를 순회하며 각 이미지를 분석하고, 모든 카테고리에 대한 확률을 집계합니다.

# predictor.py
def predict_multiple(image_paths: List[str]) -> List[Dict[str, any]]:
    model = get_model()
    processor = get_processor()
    
    aggregated_probs = defaultdict(float)
    processed_image_count = 0

    for image_path in image_paths:
        # 1. 이미지 열기 및 전처리
        image = Image.open(...) 
        inputs = processor(images=image, return_tensors="pt")

        # 2. 모델 예측
        with torch.no_grad():
            outputs = model(**inputs)
        
        # 3. 확률 계산
        probabilities = torch.nn.functional.softmax(outputs.logits, dim=-1)[0]

        # 4. 모든 카테고리의 확률을 `aggregated_probs`에 누적
        for i, prob in enumerate(probabilities):
            keyword = model.config.id2label[i]
            aggregated_probs[keyword] += prob.item()
        
        processed_image_count += 1
    ...

3단계: 평균 확률 계산 및 결과 정렬 (predictor.py)

모든 이미지의 확률을 합산한 뒤, 이미지 개수로 나누어 평균 확률을 계산합니다. 그 후, 평균 확률이 높은 순서대로 카테고리를 정렬하고 상위 2개를 선택합니다.

# predictor.py (predict_multiple 함수 계속)
    # 5. 평균 확률 계산
    if processed_image_count > 0:
        for keyword in aggregated_probs:
            aggregated_probs[keyword] /= processed_image_count

    # 6. 확률 기준으로 내림차순 정렬
    sorted_results = sorted(aggregated_probs.items(), key=lambda item: item[1], reverse=True)
    
    # 7. 상위 2개 결과 선택
    top_2 = sorted_results[:2]
    
    # 8. 최종 결과 형식으로 변환하여 반환
    final_results = [{"keyword": keyword, "probability": prob} for keyword, prob in top_2]
        
    return final_results
